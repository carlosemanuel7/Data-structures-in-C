# Data Structures I & II Repository

This repository contains exercises, implementations, and practical assignments developed during the **Data Structures I** and **Data Structures II** courses.

The goal of this repository is to document my learning journey through fundamental and advanced data structure concepts using the C programming language.

## Topics Covered

### Basic Programming Concepts
- Variables and data types
- Conditional statements
- Loops
- Functions
- Pointers

### Arrays and Strings
- One-dimensional arrays
- Multi-dimensional arrays
- String manipulation
- Searching and sorting algorithms

### Dynamic Memory Allocation
- `malloc()`
- `calloc()`
- `realloc()`
- `free()`

### Linked Lists
- Singly linked lists
- Doubly linked lists
- Circular linked lists
- Generic linked lists

### Stacks and Queues
- Stack implementation
- Queue implementation
- Applications of stacks and queues

### Trees
- Binary Trees
- Binary Search Trees (BST)
- Tree traversals
  - Preorder
  - Inorder
  - Postorder

### Hash Tables
- Hash functions
- Collision handling techniques
- Hash table implementations

### Additional Topics
- Abstract Data Types (ADT)
- Recursion
- Algorithm analysis
- Dynamic data structures

## Technologies

- Language: C
- Compiler: GCC
- Operating System: Linux

## Repository Purpose

This repository serves as:

- A personal study archive.
- A collection of solved exercises from Data Structures courses.
- A reference for reviewing data structure implementations.
- A demonstration of my progress in programming and algorithm design.
